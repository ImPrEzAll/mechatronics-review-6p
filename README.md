## 内容结构

章节顺序与考点标记完全对齐老师复习课的板书（九条主线），`★` 为板书明确点到的考点，`▲` 为课后作业已考过的题型。

| 页 | 覆盖内容 | 对应章节 |
|---|---|---|
| 1 | 五要素与三股流、绪论产品谱、机械要求与措施、滚珠丝杠全链条 | §0–§2.4 |
| 2 | 执行元件三类对比与新型执行器、传感定义指标、接口与 ADC | §3–§4 |
| 3 | 动力供给：三电系统、热管理、能量收集 | §5 |
| 4 | 控制：MCU/PLC/IPC、总线标准、PMAC/UMAC、四足机器人架构 | §6.1–6.4 |
| 5 | 控制网络与现场总线、微纳机电系统（尺度效应）、电磁兼容 | §6.5–§8 |
| 6 | 系统集成案例、高频易错辨析 14 条、公式数字速查 | §9–§11 |

章节明细：

- **§0 主线**　五类要素对应表、物质/能量/信息三股流
- **§1 绪论**　机械臂、人形机器人、数控机床、数码相机、汽车、光刻机
- **§2 机械结构**　六项要求＋五项措施、丝杠螺母四种形式与差动传动、滚珠丝杠（循环方式、精度等级、四种预紧、四种支承、三项校核）、齿轮、挠性、间歇、导轨、轴系、机座、刚度与强度之辨、MEMS、3D 打印、超材料
- **§3 执行技术**　三类执行元件对比表、有刷与无刷、伺服要求、直线电机、DEA/SMA/SMP
- **§4 传感技术**　定义与组成、静态/动态指标、误差与不确定度六点区别、常用传感器（电阻/电容/应变/光栅/编码器/位置/转速/加速度/力/温度）、莫尔条纹、三类接口、采样—量化—编码、逐次逼近与闪存型 ADC 算例、数字滤波、驻极体
- **§5 动力供给**　六种供给形式、电机分类表、三电系统、热管理、能量收集三类机理
- **§6 控制技术**　单片机/PLC/IPC、PC/XT→ISA→PC104→PCI→CPCI、PMAC/UMAC、四足机器人三级架构（PC104+DSP+CAN+QNX）、LAN 与 CSMA/CD、DCS→FCS、CAN
- **§7 微纳**　尺度效应、微能源、微传感、微流控、微纳机器人
- **§8 电磁兼容**　骚扰与干扰之辨、三要素、屏蔽、接地、滤波、隔离、软件抗干扰、设计检查清单
- **§9 集成案例**　打印机（喷墨/激光）、3D 打印与 4D 打印、立体车库、模糊控制洗衣机
- **§10 易错辨析**　14 组最容易混淆的概念对照
- **§11 速查**　核心公式与关键数字
